# STM32F103C8T6 接单开发智能体

一套面向 **STM32F103C8T6 单片机接单开发** 的智能体（AI Agent）完整配置资料，目标是：接到新设计需求后，智能体自动完成「需求解析 → 模块识别 → 引脚分配 → 业务代码(main.c) → 三轮自检 → 交付」，95% 以上的交付可直接编译烧录。

## 文件清单

| 文件 | 说明 |
|---|---|
| [智能体设计方案.md](./智能体设计方案.md) | 总体设计方案：六步工作流架构、模块识别策略、引脚自动分配与冲突检查、三轮自检机制 |
| [接单助手-系统提示词.md](./接单助手-系统提示词.md) | 可直接粘贴使用的系统提示词 v2：角色定义、固定硬件平台、知识库引用、交付规范 |
| [驱动库索引.md](./驱动库索引.md) | 私有驱动库索引（自动生成 v3）：分【库内直调】【模板】【例程移植参考】三层，是智能体判断"库内有没有"的唯一依据 |

## 快速使用

1. 阅读 `智能体设计方案.md` 了解整体架构与工作流；
2. 将 `接单助手-系统提示词.md` 全文粘贴到支持工具调用的 AI 助手（如 Claude、DeepSeek 等）作为 System Prompt；
3. 按自己的驱动库情况调整 `驱动库索引.md`（生成方式见文件头部说明）。

## 说明

- 系统提示词中的知识库路径（如 `E:/单片机模块驱动/...`）为作者本机路径，移植时请替换为你自己的驱动库路径；
- 固定硬件平台：STM32F103C8T6 + 0.96寸 OLED(SSD1306) + HAL 库 + Keil MDK5，外接模块走 USART2；
- 驱动库索引由脚本自动生成，驱动库增删后需重新生成刷新。
